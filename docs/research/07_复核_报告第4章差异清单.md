# 复核：report/sections/04_DJI_Mini_SDK与采集链路.md 与 docs/research/01-05 的差异清单

> 复核日期 2026-11-08。逐条给出：问题位置 → 正确表述 → 来源。共 10 条 + 3 处小笔误。

1. **4.1 表 line 13 与 line 21 自相矛盾（Mavic Mini 版本）**
   - 现文 line 13 把 Mini 2/Mini SE/Mavic Mini 全归为 v4.16；line 21 又写 Mavic Mini 自 v4.13。
   - 正确：Mini 2 与 Mini SE 自 **v4.16（2021-12-31）**；Mavic Mini 自 **v4.13**（依据 DJI 官方论坛帖标题，正文未抓取，属二级证据、建议标注待复核）。
   - 来源：support.dji.com 兼容表（A1）；GitHub dji-sdk/Mobile-SDK-Android releases（A11）；forum.dji.com tid=213824（B4，FAIL）。

2. **4.1 A 档 "Android+iOS" 归因过强**
   - 现文 A 档写“MSDK v4，Android+iOS”。我们只核实：官方 v4 产品页写支持平台 iOS 9.0+/Android 5.0+；但未取得 v4.16 的 iOS 版 Release Notes，dronedj（二级）称 4.16 先发 Android、iOS 随后。
   - 正确：Android 确认；iOS 应标注“v4 有 iOS SDK，但 Mini 2/Mini SE 的 iOS 版本覆盖待复核（未取得 v4.16 iOS Release Notes）”。
   - 来源：dji.com mobile-sdk-v4（A7）；dronedj 2022-01-03（B1）；references E 部分。

3. **4.2 航线表 "断点续飞仅 M30/M3E 系列" 不完整**
   - 官方原文：断点续飞支持 Matrice 30/30T、Mavic 3E/3T/3M；Mini 系列不在保证范围（不宜直接写“Mini 4 Pro 不支持”）。
   - 正确：“断点续飞官方保证机型为 M30/30T、Mavic 3E/3T/3M；Mini 系列未列入官方保证范围”。
   - 来源：MSDK v5 航线文档 data/dji/raw/text/waypoint.txt（A6）。

4. **4.2 表 "飞行安全/限高：限高限距、返航、避障开关" 缺一手证据**
   - 已核实的是 v5.3.0 新增 FlyZoneManager（限飞区查询/解禁）与 FlightController 状态类能力；"设置限高限距"未在已抓取官方文档中出现。
   - 正确：改为“FlyZoneManager（GEO/限飞区查询与解禁）+ 返航/避障状态读取”；限高限距设置删除或标注“待验证”。
   - 来源：MSDK v5.3.0 Release Notes（relnotes_all.txt）；v5 文档 missions/virtual_stick。

5. **4.2 表 "定时/等距拍照" 作为 MSDK v5 现成能力缺直接 API 证据**
   - 已证实：相机拍照、曝光参数、媒体管理（IMediaManager）；定时/间隔拍照是 DJI Fly 的相机模式，MSDK 侧通常需 App 按时间自行触发 capture（未见官方 interval 直接 API 证据）。
   - 正确：“由 App 侧定时触发 capture（间隔/等距逻辑自研）”；避免写成 SDK 内置能力。
   - 来源：MSDK v5 msdk_introduction/media_file/camera 文档（data/dji/raw/text/）。

6. **4.4 "48MP 原片" 用词不准确 + GPS 剥离结论需精确化**
   - 5 张样张均为 Lightroom/Photoshop 导出（非 SD 卡原片）；其中 2 张（Mini 3 Pro 全景、Mini 2）EXIF GPS 被剥离，但 5 张的 drone-dji XMP 均保留 GPS/云台角。另 2 张 48MP 样张为 Lightroom 导出后仍保留 GPS。
   - 正确：“48MP 照片样张（Lightroom 导出后）仍保留 GPS/云台 XMP；实测 5 张中 2 张 EXIF GPS 被导出剥离但 XMP 仍在；SD 卡原片未测”。
   - 来源：04 第 1、3 节；data/dji/samples/exif_results.json（D1-D5）。

7. **4.4 云台角精度 0.1–1° 与 03 不一致且缺官方依据**
   - 官方只给“角度抖动量 ±0.01°”（稳定重复性），不等于绝对角精度；03 的估算口径为偏航 ~1–3°、俯仰/横滚 ~0.5–2°。
   - 正确：统一为“偏航 ~1–3°、俯仰/横滚 ~0.5–2°（估算，需实测标定）；官方 ±0.01° 是稳定精度、非绝对角精度”。
   - 来源：03 第 4 节；dji.com 规格页云台“角度抖动量 ±0.01°”。

8. **4.4 GPS 精度 "实测 1–3 m" 无出处**
   - 官方标称：Mini 4 Pro 悬停精度 水平 ±0.5 m（GNSS）/±0.1 m（视觉）、垂直 ±0.5 m（GNSS）/±0.1 m（视觉）；单点绝对定位工程经验 1–5 m，需 GCP 校核。
   - 正确：改为“官方标称悬停精度 ±0.5 m(GNSS)；绝对定位误差工程经验 1–5 m（无 RTK），需 GCP/已知边长校核”。
   - 来源：dji.com/cn/mini-4-pro/specs（A14）悬停精度条；02/03 精度表。

9. **4.5 缺 Terra v5.0.0 的关键限制（可能造成误判）**
   - 缺失：Terra v5.0.0 **仅支持 Detailed Inspection 与 Agricultural Applications 两类航飞任务**，其它航线任务需用 4.5.0（而 4.5 无 3DGS）；3DGS 不支持集群/标注/量测；3DGS 的 Cesium 插件“后续版本发布”。
   - 正确：在 4.5 表“已知限制”补充上述三条，并写明“Mini 消费级自由航线数据能否直接进 Terra 5 3DGS 需实测验证”。
   - 来源：DJI Terra Release Notes v5.0.2 PDF（A21，data/dji/raw/terra_rn_5.0.2.txt）。

10. **4.5 UE5 衔接中的 Cesium 博客引用需复核**
    - 现文引用 https://cesium.com/blog/2026/04/27/3d-gaussian-splats-lod/（“2026-04 起官方支持 3DGS 3D Tiles+LOD”），本次复核 web_fetch 失败（fetch failed），无法确认 URL/日期/内容；且与官方 Notes“Terra 的 Cesium 插件后续版本发布”存在张力。
    - 正确：标注“待验证（引用需人工核对）”，或替换为 Cesium 官方文档中的 3D Tiles 对 Gaussian Splatting 支持说明。
    - 来源：05 第 4 节；Terra Release Notes（A21）。
