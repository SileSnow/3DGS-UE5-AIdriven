# 06 Mini 4 Pro 3DGS 采集 SOP（一页纸｜可直接交飞手）

> 适用：DJI Mini 4 Pro + DJI RC-N2 + Android 手机/平板；数据用于 COLMAP/3DGS 重建与 UE5 展示。依据 docs/research/01-05，版本 2026-11-08。
## 0 出门前 60 秒检查
- 设备：Mini 4 Pro、RC-N2、Android 手机（装 DJI Fly 或自研 App）、电池 ×3（充满）、microSD ≥256 GB U3 ×2、读卡器、充电宝。
- 空域：查禁飞/限高（DJI Fly 地图 + 当地空域申报/实名登记）；起降点远离人群、电线、水面。
- 天气：风速 ≤5 m/s、无雨雾；太阳高度角 30–60° 或阴天散射光。

## 1 相机参数（起飞前设定，采集全程不改变）
| 项目 | 设置 |
|---|---|
| 照片尺寸 | **48MP（8064×6048）优先**；存储/电量不足或弱光改 12MP（4000×3000） |
| 格式 | **JPEG+RAW（DNG）**；至少保留高质量 JPEG |
| 曝光 | **M 档手动**，ISO 100（阴天 200–400），EV 0 |
| 快门 | **1/500–1/1000 s**（悬停可 1/250）；禁止自动/长曝光 |
| 光圈 | f/1.7（固定不可调） |
| 白平衡 | 固定 5600K（勿自动） |
| 其他 | 关闭 HDR/自动增强/夜景/数码变焦（保持 1×）；4:3 不裁切 |
| 云台 | 主网格 -90°；五向斜视 -45°（0/90/180/270 四向）；环绕 -15°~-30° |

## 2 航线参数
- 重叠率：航向 ≥80%、旁向 ≥70%；速度 ≤3 m/s（48MP 间隔 5 s 时）。
- 高度：1 公顷 60 m；10 公顷 80–100 m；单体建筑：屋顶 50 m + 立面 20/35/50 m 三层。
- 顺序：下视双网格 → 四向 45° 斜视 → 环绕 → 难点补拍。
- DJI Fly 航点限制：≤200 点、0.1–15 m/s、不支持 KML 导入/断点续飞；航点高度为相对起飞点。

## 3 飞行中
- 同一场景不换曝光参数；换场/换时段重新测光。
- 电量 ≤30% 返航；单架次 150–200 张；发现模糊/欠曝立即停飞调整。

## 4 现场检查清单（每架次勾选）
- [ ] 空域/限高已确认，返航高度正确
- [ ] 风速 ≤5 m/s、光线稳定（无快速云影）
- [ ] 48MP/12MP、JPEG+RAW、M 档、ISO、快门、WB 固定
- [ ] 云台角度正确，数码变焦 1×
- [ ] SD 卡剩余 ≥50 GB，电池 ≥90% 起飞
- [ ] 首架次 20 张后抽查：清晰、曝光一致、EXIF/XMP 含 GPS/云台角
- [ ] 航线覆盖率目视检查（边缘外扩 ≥20%）

## 5 数据导出与命名
- 从 SD 卡直接拷贝原始 JPG/DNG（**禁止手机/微信/修图软件转存**，会剥离 EXIF/XMP，见 04）。
- 目录：data/YYYYMMDD_场景_架次/（如 20261108_campus_A01/），保留 DJI_YYYYMMDDHHMMSS_NNNN_D 原名。
- 视频如果有：同目录保留 MP4 + 同名 SRT（SRT 用于逐帧位姿先验）。
- 每架次记录：时间/天气/风速/高度/曝光/电池号/张数/GCP；交接前抽检 10 张 EXIF/XMP（可复用 data/dji/parse_exif.py）。

## 6 常见失败与补拍
| 现象 | 原因 | 补拍 |
|---|---|---|
| 水面黑洞/漂浮伪影 | 镜面反射 | 避开太阳反射角；改阴天；以岸线为控制 |
| 玻璃立面错乱 | 反射+透明 | 45° 多角度+阴天；地面补拍室内不可见部分 |
| 白墙/地面特征少 | 弱纹理 | 双网格交叉+斜视；贴临时标记；融入周边纹理 |
| 树冠模糊/重影 | 风动 | 风小窗口重飞；1/1000 s；增加重叠 |
| 局部曝光跳变 | 云影/AE 漂移 | 固定 M 档重飞该区段；同日同时段补拍 |
| 大面积运动模糊 | 速度过快/快门过慢 | 降速 ≤2 m/s、快门 ≥1/800 补拍 |

## 7 采集后交接
- 交 gs-pipeline：原片 + 架次表 + 可选 GCP 坐标；先用 COLMAP pose_prior_mapper 预跑 20–50 张验证可重建（见 03）。
- 验收标准：张数达标、重叠率达标、抽样 EXIF/XMP 完整、明显模糊帧 <5%。
