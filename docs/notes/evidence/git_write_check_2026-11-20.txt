> 来源：本次会话终端输出；原始记录在工作区研究包 `evidence/network_checks.md`。
> 用途：支撑笔记“与 origin 同步 / write 权限可用”的表述；不是本周 11-22 的复跑。

## 1. 首次核对（约 19:31，成功）

$ git push --dry-run origin HEAD

$ git ls-remote https://github.com/Gaia-Model/Gaia-2.0.git

结论：
- git push --dry-run 会与远端交互；成功说明 write 权限可用（不是只读）。
- git ls-remote 能读到 Gaia-2.0 的 refs，说明邀请已生效，至少读权限已通。

## 2. 复跑（约 19:47，网络失败）

fatal: unable to access 'https://github.com/YonganZhang/yz-global-city-resilience-paper3.git/':

结论：复跑失败是网络不可达，不是鉴权失败（鉴权失败会返回 403/401 或 Permission denied）。
