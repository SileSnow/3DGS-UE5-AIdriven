## 4. 卡点（按优先级）与已核实的证据

### P0-1 数据源：该仓库里没有 3D 场景资产 `[已核查]`

对 `YonganZhang/yz-global-city-resilience-paper3` 的完整 git 树（`main`，**10,643 个 blob**）做过扫描：

| 检查项 | 结果 |

| Release 资产 / submodule / Git LFS | 无 release、无 `.gitmodules`、无 LFS 指针 |
| 数据目录 | `_data/README.md` 原文："**输入数据（不进 Git）**"，即原始栅格与遥感数据只在作者本地 |
| 与"海啸"相关的目录 | 仅 `_sandbox/2026-10-25-giri-tsunami-scenario-availability`（研究 GIRI/NGI 的**源级海啸情景包是否公开可取**，结论：取不到逐情景数据）、`_sandbox/2026-10-25-fast-tsunami-inundation-options`（DEM 淹没试点）——都是 **2D 风险建模**，不是城市三维资产 |
| "城市几何"实际是什么 | `_sandbox/2026-10-25-global-city-geometry-*`：UCDB 城市**面** + GHSL 建成区栅格，用于城市级暴露统计，不是可渲染三维场景 |

**含义**：学长指的"东京条件海啸 / 城市三维资产场景数据"要么在他本地（不进 Git，我们拿不到），要么在另一个仓库/网盘。**11-22 的节点直接卡在这里**，必须先问清，不能自己猜着做。

给学长的选项（回信里三选一，见 `replies/2026-11-16-回信草稿.md`）：
1. **给具体位置**：本地路径 → 打包/网盘/私有 Release（推荐，最快）；
2. **给仓库名**：如果实际在另一个仓库，我们直接 clone；
3. **降级自建**：我们用公开数据（OSM 建筑体块 + 地形）搭一个 ≤300 m 的东京小区域，2–3 天可出可跑通的演示，但**资产不是宙斯平台的**，需要在 manifest 里写清来源。

## 6. 采购前 MSDK v5 核查结论（可直接转发给学长）

结论：**Mini 4 Pro 可以买，但必须按下面这套配置买，且有一个点只能靠真机验证。**

| 项 | 结论 | 依据 |
|---|---|---|
| SDK 支持 | **MSDK v5.13.0（2025-03-17）起支持 Mini 4 Pro**；当前最新 5.20.1 | 官方 Release Notes / 兼容表，见 `docs/research/01` §1.4 |
| 平台 | **仅 Android**（iOS 无 v5）；Android 10+、arm64 | 官方产品页 + Release Notes |
| 遥控器 | **RC-N2**（v5.13.0 起）/ **RC-N3**（v5.17.0 起）；**带屏 DJI RC 2 永远不支持** | 官方固件表 |
| 航点任务 | 接口在：`WaypointMissionManager.pushKMZFileToAircraft → getAvailableWaylineIDs → startMission` | `docs/research/08` §6.x，API 页已核对 |
| 虚拟摇杆 | 接口在：`VirtualStickManager.enableVirtualStick`（需 N 档、飞机不在自动任务中） | `docs/research/08` §6.7 |
| **唯一硬伤风险** | **KMZ/WPML 是否被 Mini 4 Pro 飞控接受，官方文档未明确列出，必须真机试** | `msdk_bridge/SUMMARY.md` 风险 #3 |
| 兜底 | DJI Fly **原生航点**支持 Mini 4 Pro（单线 ≤200 点，0.1–15 m/s）→ 即使 SDK 航点不通，也能半自动完成采集 | `docs/research/01` §1.6 |

采购清单建议：Mini 4 Pro（RC-N2 套装）+ 一台 Android 10+ arm64 手机。**不建议**买带屏 RC 2 套装（装不了第三方 App，整条 MSDK 路线直接断）。
